# Practice 10 — Students Async

Flutter-приложение для практики асинхронного программирования.

## Запуск

```bash
flutter pub get
flutter run -d macos
```

На главном экране доступны By hand, FutureBuilder и Countdown.

## Проверка сценариев

- By hand: загрузка занимает две секунды. Нажмите обновление дважды после первого ответа, чтобы третий запрос показал ошибку. Retry запускает четвёртый запрос.
- Save: после свежего запуска первое сохранение закрывает экран; откройте By hand ещё раз — второе сохранение покажет отказ сервера. Кнопка отключена во время ожидания.
- FutureBuilder: Switch меняет плотность списка; в консоли не появляются новые запросы. Кнопка обновления запускает запрос явно.
- Countdown: A использует StreamBuilder, B — ручную подписку. При переключении выбранная версия начинает отсчёт заново. После закрытия экрана события прекращаются.

